دکتر پیامک

این صفحه دقیقاً همان درخواستی را می‌فرستد که فرم ثبت‌نام سایت می‌فرستد، و پاسخ خام سرور را نشان می‌دهد. با این کار معلوم می‌شود مشکل کجاست: «سامانه‌ی پیامک تنظیم نشده»، «فاصله‌ی ۶۰ ثانیه‌ای»، یا «خطای پنل پیامکی».
هیچ چیزی روی سایت شما تغییر نمی‌کند و کد ارسالی فقط برای همان شماره است.

همان شماره‌ای که می‌خواهید کاربر جدید با آن ثبت‌نام کند.

  


  

    
بررسی کد

    

      کدی که دیدید (یا با پیامک رسید) را این‌جا بزنید تا مطمئن شویم همان کد پذیرفته می‌شود.
    

    

    
    
    
    

  


  

    
پاک‌کردن قفل ۶۰ ثانیه

    

      اگر پیام «تا N ثانیه‌ی دیگر صبر کنید» می‌گیرید، این دستور را در
      Supabase → SQL Editor اجرا کنید تا فوراً بتوانید دوباره کد بگیرید.
    

    

    
  


  

    
راه‌اندازی sms.ir (پیشنهادی)

    

      سایت از دو سامانه پشتیبانی می‌کند: sms.ir و کاوه‌نگار. اگر سکرت
      SMS_IR_API_KEY (یا SMSIR_API_KEY) تنظیم باشد،
      مسیر پیامک از sms.ir می‌رود.
    


    
۱) در پنل sms.ir

    
    
      
  1. وارد app.sms.ir شوید → منوی برنامه‌نویسان →
          لیست کلیدهای API → ایجاد کلید جدید →
          نوع Production (برای تست، نوع Sandbox هم هست).
    2. 
      
  2. کلید ساخته‌شده را کپی کنید (فقط یک‌بار کامل نشان داده می‌شود).
    3. 
      
  3. از منو بروید به ارسال سریع (ارسال با قالب / Verify) →
          ایجاد قالب جدید. متن قالب را مثلاً این بگذارید:
          
    کد تایید شما در آکادمی استاد مهدی عزیزی: #CODE#
          
    در متن قالب حتماً عبارت «کد تایید» باشد و متغیر #CODE#
          داخلش قرار بگیرد. بعد از تأیید قالب، شناسه‌ی قالب (یک عدد) را
          یادداشت کنید.
    4. 
      
  4. اگر پنل می‌گوید «خط ارسال‌کننده نیاز به فعال‌سازی دارد»، خط خدماتی‌تان را
          در پنل فعال کنید یا با پشتیبانی sms.ir تماس بگیرید.
    5. 
    


    
۲) در Supabase

    
    
      
  1. وارد supabase.com/dashboard شوید و پروژه را باز کنید.
    2. 
      
  2. منوی چپ: Project Settings → بخش Edge Functions → Secrets
          (یا در نسخه‌های جدید: Edge Functions → تب Secrets).
    3. 
      
  3. روی Add new secret بزنید و این دو سکرت را بسازید
          (هر دو نام‌گذاری قبول است؛ همان که دارید را نگه دارید):
        
      
          
    • SMS_IR_API_KEY یا SMSIR_API_KEY = کلیدی که
              از پنل sms.ir کپی کردید
      • 
          
    • SMS_IR_TEMPLATE_ID یا SMSIR_TEMPLATE_ID =
              شناسه‌ی عددی قالب کد تأیید
      • 
        
    
      
    4. 
      
  4. Save. بعد از ذخیره‌ی سکرت، فانکشن send-otp را یک‌بار
          دوباره Deploy کنید (Supabase → Edge Functions → send-otp →
          Deploy) تا کد جدید و سکرت‌ها با هم فعال شوند.
    5. 
      
  5. دوباره دکمه‌ی «ارسال کد تایید» همین صفحه را بزنید — باید بنویسد
          «پیامک ارسال شد».
    6. 
    


    

      سکرت‌های اختیاری: SMS_IR_OTP_PARAMETER اگر نام متغیر قالب شما
      CODE نیست · SMS_IR_LINE_NUMBER برای ارسال با خط
      اختصاصی (روش Bulk، بدون قالب) · OTP_DEBUG=true برای دیدن کد در
      پاسخ هنگام تست (بعد از تست حتماً حذفش کنید) ·
      KAVENEGAR_API_KEY فقط اگر خواستید به کاوه‌نگار برگردید.
