دکتر پیامک

این صفحه همان route هم‌مبدأ Next.js را که فرم ثبت‌نام استفاده می‌کند صدا می‌زند و پاسخ خام سرور را نشان می‌دهد. با این کار معلوم می‌شود مشکل کجاست: «سامانه‌ی پیامک تنظیم نشده»، «فاصله‌ی ۶۰ ثانیه‌ای»، یا «خطای پنل پیامکی».
این دکمه واقعاً یک درخواست OTP می‌فرستد؛ ممکن است ردیف کوتاه‌عمر در PostgreSQL بسازد و پیامک واقعی ارسال کند/هزینه داشته باشد. فقط برای شماره‌ای که اجازه‌ی تستش را دارید استفاده کنید؛ حساب یا پروفایل ساخته نمی‌شود.

همان شماره‌ای که می‌خواهید کاربر جدید با آن ثبت‌نام کند.

  


  

    
بررسی کد

    

      کدی که دیدید (یا با پیامک رسید) را این‌جا بزنید تا مطمئن شویم همان کد پذیرفته می‌شود.
    

    

    
    
    
    

  


  

    
راه‌اندازی sms.ir (پیشنهادی)

    

      سایت از دو سامانه پشتیبانی می‌کند: sms.ir و کاوه‌نگار. اگر سکرت
      SMS_IR_API_KEY (یا SMSIR_API_KEY) تنظیم باشد،
      مسیر پیامک از sms.ir می‌رود.
    


    
۱) در پنل sms.ir

    
    
      
  1. وارد app.sms.ir شوید → منوی برنامه‌نویسان →
          لیست کلیدهای API → ایجاد کلید جدید →
          نوع Production (برای تست، نوع Sandbox هم هست).
    2. 
      
  2. کلید ساخته‌شده را کپی کنید (فقط یک‌بار کامل نشان داده می‌شود).
    3. 
      
  3. از منو بروید به ارسال سریع (ارسال با قالب / Verify) →
          ایجاد قالب جدید. متن قالب را مثلاً این بگذارید:
          
    کد تایید شما در آکادمی استاد مهدی عزیزی: #CODE#
          
    در متن قالب حتماً عبارت «کد تایید» باشد و متغیر #CODE#
          داخلش قرار بگیرد. بعد از تأیید قالب، شناسه‌ی قالب (یک عدد) را
          یادداشت کنید.
    4. 
      
  4. اگر پنل می‌گوید «خط ارسال‌کننده نیاز به فعال‌سازی دارد»، خط خدماتی‌تان را
          در پنل فعال کنید یا با پشتیبانی sms.ir تماس بگیرید.
    5. 
    


    
۲) در محیط سرور Next.js

    
    
      
  1. مقادیر provider را در environment سرویس Next.js تنظیم کنید؛ برای Compose، فایل `.env` کنار دستور Compose خوانده می‌شود و `compose.yaml` آن‌ها را به کانتینر می‌دهد.
    2. 
      
  2. برای sms.ir این دو متغیر را بسازید (نام‌های بدون underscore هم پشتیبانی می‌شوند):
        
      
          
    • SMS_IR_API_KEY یا SMSIR_API_KEY = کلیدی که از پنل sms.ir کپی کردید
      • 
          
    • SMS_IR_TEMPLATE_ID یا SMSIR_TEMPLATE_ID = شناسه‌ی عددی قالب کد تأیید
      • 
        
    
      
    3. 
      
  3. اگر قالب Verify ندارید، به‌جای template ID می‌توانید SMS_IR_LINE_NUMBER یا SMSIR_LINE_NUMBER تنظیم کنید. برای کاوه‌نگار، KAVENEGAR_API_KEY را وارد کنید.
    4. 
      
  4. بعد از تغییر environment، سرویس Next.js را restart/redeploy کنید؛ deploy کردن Edge Function لازم نیست. سپس دوباره دکمه‌ی «ارسال کد تایید» را بزنید — باید بنویسد «پیامک ارسال شد».
    5. 
    


    

      سکرت‌های اختیاری: SMS_IR_OTP_PARAMETER اگر نام متغیر قالب شما
      CODE نیست · SMS_IR_LINE_NUMBER برای ارسال با خط
      اختصاصی (روش Bulk، بدون قالب) · OTP_DEBUG=true برای دیدن کد در
      پاسخ فقط در محیط development (در production هرگز کد را افشا نمی‌کند) ·
      KAVENEGAR_API_KEY فقط اگر خواستید به کاوه‌نگار برگردید.
