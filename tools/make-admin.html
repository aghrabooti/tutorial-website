ساخت مدیر اولیه

فرم مرورگری و تولید SQL این صفحه بازنشسته شده است. در نسخه‌ی self-hosted رمز مدیر را در مرورگر وارد نکنید و هیچ دستور ارتقای نقش را دستی در دیتابیس اجرا نکنید.

روش امن روی VPS

  1. ابتدا staging را طبق راهنمای deploy/self-hosted/README.md بالا بیاورید و migration را بررسی کنید.
  2. از SSH تعاملی و ریشه‌ی مخزن، دستور زیر را اجرا کنید:
docker compose --env-file .env -f deploy/self-hosted/compose.yaml exec -it next-app \
  node --conditions=react-server scripts/create-admin.js

ابزار شماره را نرمال می‌کند، رمز را بدون echo می‌گیرد و تکرار می‌خواهد؛ حداقل رمز ۱۲ نویسه است. فقط وقتی هیچ مدیر یا شماره‌ی تکراری در PostgreSQL نباشد، یک مدیر تازه می‌سازد و حساب موجود را ارتقا/بازنویسی نمی‌کند. اجرای آن از shell غیرتعاملی عمداً رد می‌شود.

قبل از ساخت production

ابتدا نسخه‌ی staging را با DB خالی، backup خارج از VPS و restore آزمایش کنید. Supabase/Vercel قدیمی را تا پایان rollback window روشن نگه دارید؛ bootstrap مدیر این سرویس‌های قدیمی را تغییر نمی‌دهد. اگر این مسیر مستقیماً در دامنه‌ی production باز شده، آن را فقط راهنمای عملیاتی بدانید و عملیات ساخت مدیر را از SSH انجام دهید.
