ساخت حساب مدیر

این صفحه یک دستور SQL برای شما می‌سازد که همان شماره موبایل را با نقش «مدیر» در سایت ثبت می‌کند.
🔒 رمز عبور شما فقط در مرورگر خودتان پردازش می‌شود و به هیچ سروری فرستاده نمی‌شود؛ خروجی فقط «اثر انگشت رمز» است.

هر فرمتی بنویسید (۰۹۱۲… یا +۹۸۹۱۲… یا ۹۸۹۱۲…) — خودش استاندارد می‌کند.
این رمز را جایی امن نگه دارید؛ برای ورود به admin.mahdiazizi.com لازمش دارید.

دستور آماده است ✅

کادر زیر را کپی کنید و در Supabase اجرا کنید. مراحل دقیق پایین‌تر آمده است. 



    

    

      
حالا کجا بچسبانم؟

      
    
        
  1. برو به supabase.com/dashboard و پروژه‌ی سایت را باز کن.
    2. 
        
  2. از منوی چپ: SQL Editor → دکمه‌ی New query.
    3. 
        
  3. دستور بالا را پیست کن (Ctrl+V).
    4. 
        
  4. دکمه‌ی Run (پایین‌راست یا Ctrl+Enter) را بزن.
    5. 
        
  5. در آخرین جدول نتیجه، باید یک ردیف با role = admin ببینی.
    6. 
        
  6. برو به admin.mahdiazizi.com و با همین شماره و رمز وارد شو.
